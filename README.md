# ApexPlanet Task 3 – Web Application Security

## Objective
This project demonstrates common web application vulnerabilities
using DVWA in a controlled Kali Linux laboratory environment.

## Vulnerabilities Demonstrated
- SQL Injection
- Stored XSS
- Reflected XSS
- CSRF
- Local File Inclusion
- Remote File Inclusion
- Burp Suite Intercept
- Burp Suite Intruder
- HTTP Security Headers

## Tools Used
- Kali Linux
- DVWA
- Docker
- Burp Suite Community Edition

## Mitigations Studied
- Prepared Statements
- Input Validation
- Content Security Policy
- CSRF Tokens
- File Allowlisting
- HTTP Security Headers

## Report
See the `Report` directory for the complete security testing report.

## Conclusion
All testing was performed in an isolated, controlled laboratory
environment for educational purposes.
